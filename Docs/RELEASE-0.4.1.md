# ROSMÁN · Vocoder — 0.4.1

El nombre visible de la interfaz ahora es **ROSMÁN**, con **Vocoder** debajo.
El acento y las dos líneas están dibujados como texto nativo. La información de
bandas, modo y frecuencia de muestreo se consulta al dejar el cursor sobre Vocoder.

Esta actualización cambia únicamente el encabezado. Conserva sonido, controles,
parámetros y compatibilidad con las sesiones guardadas. Los nombres de los formatos
que encuentra el DAW y los archivos de instalación siguen siendo R-Vocoder.

Compilación universal para Apple Silicon e Intel. Se revisó la interfaz normal y
mínima y se ejecutaron las pruebas existentes de integración y auval para los dos AU.
[Integración](Validation/integration-0.4.1.txt) · [AU](Validation/au-effect-0.4.1.txt) ·
[AU MIDI](Validation/au-midi-0.4.1.txt).
Los resultados del motor de audio se documentan en [0.4](RELEASE-0.4.md).

Descomprime el ZIP y ejecuta Install.command. Guarda tu sesión y vuelve a abrir
Logic/Ableton para cargar la actualización. Sigue siendo una beta con firma ad hoc,
sin notarización de Apple.
